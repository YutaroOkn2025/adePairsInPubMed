# adePairsInPubMed
This is a dataset for predicting the first reported ADE pair in PubMed.<p>
The paper titled "Predicting and Classifying First Reports of Adverse Drug Events in Biomedical Literature based on Authors' Arguments" was published in the peer-reviewed journal Interdisciplinary Information Sciences (Vol. 31, No. 1, pp. 96–109, November 2025).<p>
